
# ColorMate MLOps

AI Personal Color Analysis & Makeup Recommendation System.

## Project Overview

ColorMate is a Machine Learning-based system designed
to help beauty store customers analyze personal color
and receive makeup product recommendations.

## Main Features

- AI-based personal color classification
- Color palette recommendation
- Makeup product matching
- Customer interface
- Staff dashboard
- MLOps training pipeline
- Model deployment and monitoring
- Feedback and model retraining

## Technology Stack

- Python

- DVC
- FastAPI
- Docker
